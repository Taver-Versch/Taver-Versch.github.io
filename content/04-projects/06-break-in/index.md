> **Note:** Break.In is still in development, we are planning to release it in December 2026.

Break.In is a multiplayer horror game that I am making with Amtav Games, the indie game studio I co-founded in March 2026. I am the Lead Developer, so most of my time on this goes into the code and keeping development on track.

## The game
- **Engine:** built in Unity with C#, and we use Blender for the 3D side of things.
- **Multiplayer:** uses Steam peer-to-peer networking, so players can host games themselves through Steam.
- **How we work:** we plan and deliver everything in Agile Scrum sprints.
